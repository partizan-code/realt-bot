# Настройка и запуск

[К документации](README.md) · [Обзор проекта](../README.md)

## Окружение

Нужны Git и uv. Минимальная версия Python — 3.12; [`.python-version`](../.python-version) выбирает 3.13. Манифест и настройки Ruff находятся в [pyproject.toml](../pyproject.toml), точные версии зависимостей — в [uv.lock](../uv.lock).

```bash
git clone https://github.com/partizan-code/realt-bot.git
cd realt-bot
uv sync --locked
uv run --locked playwright install chromium
```

`uv sync --locked` создаёт проектное `.venv` и устанавливает зависимости по lock-файлу. Для `uv run` ручная активация окружения не нужна.

На Linux при необходимости системных библиотек Chromium используйте с соответствующими правами:

```bash
uv run --locked playwright install --with-deps chromium
```

В VS Code выберите `Python: Select Interpreter`: `.venv/Scripts/python.exe` на Windows или `.venv/bin/python` на macOS/Linux. Наличие матрицы CI Windows/Linux не заменяет проверку конкретной машины; отдельный прогон на macOS здесь не заявляется.

## Переменные окружения

Скопируйте [`.env.example`](../.env.example) в `.env` в корне проекта. В шаблоне перечислены комментарии, а не активные присваивания: добавьте строки вида `ИМЯ=значение` со своими реквизитами.

| Переменная | Назначение |
| --- | --- |
| `TOKEN` | Токен Telegram-бота |
| `ADMIN_ID` | Числовой ID администратора; обязателен для проверки конфигурации, в текущем потоке публикации не используется |
| `MINSK_CH_ID` | Числовой ID канала Минска |
| `GOMEL_CH_ID` | Числовой ID канала Гомеля |
| `MOGILEV_CH_ID` | Числовой ID канала Могилёва |
| `VITEBSK_CH_ID` | Числовой ID канала Витебска |
| `GRODNO_CH_ID` | Числовой ID канала Гродно |
| `BREST_CH_ID` | Числовой ID канала Бреста |

`config.configure()` читает корневой `.env` и проверяет наличие всех переменных и целочисленность ID. Уже заданные переменные процесса имеют приоритет перед `.env`. Импорт конфигурации сам по себе не загружает `.env`; загрузка выполняется при запуске приложения.

Добавьте бота во все целевые каналы с правом публикации. Для первого запуска используйте тестовые каналы. Проверьте ссылки в `config.SIGNATURE`: они задаются отдельно от ID и должны вести в ваши каналы.

Остальные параметры Python собраны в [config.py](../config.py): города, URL и селекторы, лимит истории, интервалы, таймауты, Chromium, Telegram, Loguru и диагностический скрипт. Секреты в этот файл не записывайте.

## Необязательная сессия браузера

Если требуется сохранённая сессия, файл `re.kufar.by_cookies.json` передаётся в `browser.new_context(storage_state=...)`. Нужен объект состояния Playwright с `cookies` и `origins`, а не верхнеуровневый список из расширения экспорта cookies. Переименование файла не преобразует формат.

В объекте cookies Playwright срок действия задаётся полем `expires`; поле `expirationDate` из некоторых расширений экспорта ему автоматически не сопоставляется. Допустимую структуру сверяйте с [описанием `storage_state`](https://playwright.dev/python/docs/api/class-browser#browser-new-context-option-storage-state) для используемой версии Playwright. Сам файл содержит чувствительные данные; для проверки формата не требуется публиковать значения cookies.

Неподходящий локальный файл не доказывает неисправность production: формат серверного файла и серверное окружение могли отличаться. Сначала отдельно установите фактический источник сессии и формат на целевой машине; преобразование и перезапись требуют разрешения и сохранения оригинала.

Без файла Chromium начинает новую сессию. Автоматического сохранения cookies нет. Не публикуйте содержимое сессии; при несовместимом формате отдельно подготовьте корректный файл, сохранив исходный.

## Запуск и рабочий каталог

Запускайте из корня проекта:

```bash
uv run --locked python main.py
```

Команда открывает Kufar и публикует в каналы из окружения; это не проверка конфигурации без побочных эффектов. Остановка — `Ctrl+C`.

`.env` привязан к корню проекта, но пути истории, cookies и `error.log` зависят от текущего рабочего каталога. Используйте один экземпляр приложения: блокировок истории нет.

Для окружения без инструментов разработки:

```bash
uv sync --locked --no-dev
uv run --locked --no-dev python main.py
```

Chromium в таком окружении установите через `uv run --locked --no-dev playwright install chromium`. Настройка сервера и ограничения шаблонов деплоя — в [OPERATIONS.md](OPERATIONS.md).

## Воспроизводимость серверного окружения

Наличие `pyproject.toml` и `uv.lock` фиксирует зависимости проекта, но не подтверждает состав уже работающего серверного venv. Перед согласованным обновлением зафиксируйте фактические версии Python, установленных пакетов, Playwright/Chromium и команду запуска, не обновляя рабочую среду ради инвентаризации. Отдельное окружение проверяется по согласованным требованиям; настройки и данные рабочего процесса сохраняются для отката.

Оценка известных уязвимостей требует фактических версий пакетов и отдельной проверки. Историческое отсутствие lock-файла или неполное знание production-окружения не является доказательством конкретной CVE. Проверка текущих зависимостей на уязвимости здесь не выполнялась.
